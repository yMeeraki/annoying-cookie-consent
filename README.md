# Annoying Cookie Consent

A fun frontend project that simulates a dark-pattern cookie consent modal.

## Features
- Delayed modal popup
- Form submission using `FormData`
- Fake loading animation with `setTimeout`
- Dynamic DOM updates
- "Decline" button avoids the user on hover

## Tech Stack
- HTML
- CSS (Flexbox)
- JavaScript (DOM Manipulation, Events)

## What I Learned
- Handling form data in JS
- Updating UI dynamically
- Working with event listeners
- Creating interactive UX patterns
